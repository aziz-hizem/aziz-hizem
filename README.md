## 🚀 A few projects

| Project | What it is |
|---|---|
| [**azure-devops-cicd-pipeline**](https://github.com/aziz-hizem/azure-devops-cicd-pipeline) | A full delivery pipeline on Azure: tests, security scanning, a SonarQube quality gate that blocks bad code, Docker packaging and promotion to production behind a manual approval. Built during a two-month DevOps internship at an airline. |
| [**pill-blister-classifier**](https://github.com/aziz-hizem/pill-blister-classifier) | Inspects pill blister packs with OpenCV, no machine learning: counts pills, detects empty cells, flags colour anomalies. Runs on a desktop and on a Raspberry Pi 5 with LEDs and a servo. |
| [**spiderbot-rust-detection**](https://github.com/aziz-hizem/spiderbot-rust-detection) | Rust and corrosion detection for an inspection robot. Three YOLO models trained and compared; the robot's Raspberry Pi streams its camera over Wi-Fi to a workstation running detection. |
| [**F1-Chatbot-V2**](https://github.com/aziz-hizem/F1-Chatbot-V2) | Ask about Formula 1 history in plain English. An LLM writes the SQL, the query runs read-only against every season from 1950 to 2024, and the answer comes back as a sentence. |
| [**cinecasa**](https://github.com/aziz-hizem/cinecasa) | A desktop app that turns local movie and TV folders into a streaming-style library, with TMDB artwork and playback that resumes at the exact second you stopped. |
| [**astar-pathfinding-visualizer**](https://github.com/aziz-hizem/astar-pathfinding-visualizer) | A maze editor that shows the A\* algorithm exploring the grid, one step at a time. Written from scratch. |

Smaller tools, games and prototypes are in the repository list below, and all of them are on my
[portfolio](https://aziz-hizem.github.io).
