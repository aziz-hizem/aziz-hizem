## 🚀 A few projects

| Project | What it is |
|---|---|
| [**f1-chatbot**](https://github.com/aziz-hizem/f1-chatbot) | Ask about Formula 1 history in plain English. An LLM writes the SQL, the query runs read-only against every season from 1950 to 2024, and the answer comes back as a sentence. |
| [**azure-devops-cicd-pipeline**](https://github.com/aziz-hizem/azure-devops-cicd-pipeline) | A full delivery pipeline on Azure: tests, security scanning, a SonarQube quality gate that blocks bad code, Docker packaging and promotion to production behind a manual approval. Built during a two-month DevOps internship at an airline. |
| [**flappy-fish-neat-ai**](https://github.com/aziz-hizem/flappy-fish-neat-ai) | Neural networks teach themselves to play an underwater Flappy Bird clone with NEAT neuroevolution: 50 fish per generation, the fittest breed the next. Playable by hand too. |
| [**spotify-chatbot**](https://github.com/aziz-hizem/spotify-chatbot) | Manage your Spotify playlists by chatting in plain English. An LLM turns each request into a JSON action run on the Spotify Web API, plus a RAG experiment that retrieves API docs so the LLM can write new actions. |
| [**spiderbot-rust-detection**](https://github.com/aziz-hizem/spiderbot-rust-detection) | Rust and corrosion detection for an inspection robot. Three YOLO models trained and compared; the robot's Raspberry Pi streams its camera over Wi-Fi to a workstation running detection. |
| [**pill-blister-classifier**](https://github.com/aziz-hizem/pill-blister-classifier) | Inspects pill blister packs with OpenCV, no machine learning: counts pills, detects empty cells, flags colour anomalies. Runs on a desktop and on a Raspberry Pi 5 with LEDs and a servo. |
| [**shakedown**](https://github.com/aziz-hizem/shakedown) 🚧 | *Currently building.* Test-deploys every pull request before it is merged: compares startup, memory, image size and vulnerabilities with main, and blocks serious regressions. |
